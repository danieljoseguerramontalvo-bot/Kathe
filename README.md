# Katherine 💛

Una página hecha con amor para Katherine: sus fotos, un video y una cartita.

## Ver la página

Es un sitio estático simple, sin build. Solo abre `index.html` en el navegador,
o sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

Luego entra a `http://localhost:8000`.

## Estructura

- `index.html` — la página
- `styles.css` — estilos
- `assets/images/` — fotos de Katherine
- `assets/video/` — video de Katherine
